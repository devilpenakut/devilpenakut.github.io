Amazon menawarkan pengguna program Shopper Panel-nya $ 2 per bulan untuk memantau data telepon dan memverifikasi iklan. Program ini saat ini hanya untuk undangan, dengan pengguna bisa bergabung di daftar tunggu untuk mungkin diundang di kemudian hari.

Amazon belum mengomentari alasan di balik implementasi program verifikasi iklan. Situs Shopper Panel menyatakan bahwa pengguna dapat memperoleh hadiah dengan berbagi setruk pembelian yang dibuat di luar Amazon.com dan menyelesaikan survei pendek.

Pengguna dapat mengaktifkan verifikasi iklan untuk mengonfirmasi iklan yang telah mereka lihat di perangkat mereka. Amazon telah menyatakan bahwa pengguna dapat membatalkan verifikasi iklan kapan saja.

Business Insider melaporkan bahwa program ini hanya untuk undangan, tetapi pengguna yang belum diundang dapat bergabung di daftar tunggu. Seorang juru bicara Amazon menolak berkomentar tentang cara pengguna dipilih untuk program ini.

Program Amazon Shopper Panel adalah program eksklusif dan hanya untuk undangan. Ini menampilkan program verifikasi iklan, di mana pengguna dapat memperoleh hadiah dengan berbagi setruk dan menyelesaikan survei. Pengguna juga dapat mengaktifkan verifikasi iklan untuk mengonfirmasi iklan yang mereka lihat di perangkat mereka, mendapatkan hadiah bulanan sebesar $ 2.

Program ini saat ini hanya untuk undangan, tetapi pengguna dapat bergabung di daftar tunggu untuk mungkin diundang di kemudian hari. Amazon belum mengomentari alasan untuk menerapkan program ini.
