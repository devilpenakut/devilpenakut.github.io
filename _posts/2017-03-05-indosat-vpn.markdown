### Bagaimana pengaruhnya?

![Screenshot_20170305-130816](https://i1.wp.com/devilpenakut.com/wp-content/uploads/2017/03/Screenshot_20170305-130816.png?resize=549%2C976)

Bagi pengguna Indosat mungkin tidak awam dengan aplikasi MyCare Indosat yang
sekarang berubah menjadi MYIM3.

Walau sempat kacau diawal namun saat ini apllikasi MYIM3 bisa dianggap sudah
banyak fitur baru, tapi tidak menhilangkan keanehan selalu minta login ketika
memuka aplikasi ini.

Salah satu fitur yang menarik adalah fitur ‘kontrol’ dimana merupakan Mode
Hemat Data menurut Indosat. Tentunya dengan hemat data juga hemat uang, karena
pengeluaran untuk beli paket data berkurang.

Ternyata, dalam mode hemat data ini Indosat memakai VPN khusus. Jadi
pronsipnya sama dengan mode hemat data [Opera
MAX](http://www.opera.com/id/apps/max).

### Kecepatan

Bagaimana dengan kecepatan menggunakan ‘Indosat VPN’ ini ? Tentunya dengan
menggunakan VPN maka akan ada pengurangan kecepatan karena terjadi perputaran
jalur.

Ini adalah kecepatan yang dites menggunakan layanan [Fast](fast.com) sebelum
menggukanan mode hemat data

![Screenshot_20170305-130852](https://i1.wp.com/devilpenakut.com/wp-content/uploads/2017/03/Screenshot_20170305-130852.png?resize=548%2C974)

Setelah menggunakan mode hemat data terjadi pengurangan kecepatan namun tidak
terlalu drastis

![Screenshot_20170305-131012](https://i0.wp.com/devilpenakut.com/wp-content/uploads/2017/03/Screenshot_20170305-131012.png?resize=548%2C974)

Kecepatan ini memang tergantung kecepatan jaringan asli. Ketika saya coba ini
menggunakan jaringan MNC Play yang /download/-nya upto 7 Mbps.

Namun ketika saya coba menggunakan jaringan Indosat yang memang tidak bagus
maka kecepatan ketika memakai mode hemat data ini makin membuat sedih.

Oh iya ini tambahan perbandingan ketika memakai Opera VPN

![Screenshot_20170305-135711](https://i0.wp.com/devilpenakut.com/wp-content/uploads/2017/03/Screenshot_20170305-135711.png?resize=549%2C976)

Ternyata kecepatannya jauh menurun. Lebih baik menggunakan mode hemat data.

### Hemat Data?

![Screenshot_20170305-131133](https://i0.wp.com/devilpenakut.com/wp-content/uploads/2017/03/Screenshot_20170305-131133-1.png?resize=548%2C974)

Tadi saya sempat coba dari pagi, namun penghematan yang saya dapat cuma 0,05
Mb atau 50 Kb. tidak terlalu signifikan. Mungkin perlu coba lebih lama lagi.

### VPN di Indihome membuka akses Netflix?

Kalau memang penurunan kecepatan tidak terlalu banyak, bagaimana bisa VPN ini
digunakan untuk membuka blokir Indihome terhadap aplikasi Netflix. Kita tahu,
Indosat tidak memblokir aplikasi Netflix, yang berarti seharusnya Netflix bisa
diakses menggunakan ‘VPN Indosat’ ini.

Sekarang karena saya menggunakan jaringan MNC Play yang tidak memblokir
Netflix baik menggunakan mode hemat data maupun tidak saya dapat mengakses
Netflix. Nanti saya coba ketika saya berada dijaringan Indihome.

#### Update

Ternyata tidak pengaruh. VPN ini hanya berguna untuk penghemat data saja
seperti fungsi awalnya. IP masih merupakan IP asli, dan Netflix masih
diblokir.
