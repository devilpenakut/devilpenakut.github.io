Saya suka memakai [Pocket ](https://getpocket.com/)untuk menyimpan artikel
yang menarik dari web yang belum sempat saya baca. Masalahnya aplikasi Pocket
terutama di iOS banyak memakan tempat penyimpanan. Padahal untuk membaca saya
tetap suka menggunakan versi web nya di desktop.

getpocket.com

Kenapa saya membutuhkan aplikasi nya? Karena untuk menyimpan artikel dari
browser di ponsel/tablet bisa langsung share to Pocket.

Nah bagaimana cara bisa menyimpan di Pocket tapi tanpa aplikasinya?

Untuk beberapa aplikasi seperti [Flipboard](https://flipboard.com/), sudah
diinstal langsung untuk menyimpan ke Pocket, namun untuk banyak aplikasi
lainnya tidak tersedia, dan bergantung share dari aplikasi Pocket.

Nah, akhirnya saya menemukan cara untuk menyimpan di Pocket tanpa install
aplikasinya yaitu menggunakan [Pocket Bot](https://telegram.me/pockebot) di
aplikasi Telegram. Telegram itu aplikasi untuk bertukar pesan seperti
Whatsapp, namun beda dengan WA, Telegram bisa menggunakan bot seperti halnya
Facebook Messenger. Fitur itu yang bisa digunakan pengembang untuk menanamkan
aplikasi di dalam aplikasi Telegram.

![Screenshot-2018-1-9 Telegram Web](https://i1.wp.com/devilpenakut.com/wp-content/uploads/2018/01/Screenshot-2018-1-9-Telegram-Web.png?resize=466%2C229)

Untuk menyimpan link ke Pocket menggunakan Telegram dengan bot itu, cukup
untuk mengirimkan pesan ke Pocket Bot seperti kita share link ke WA. Nanti
secara otomatis link yang kita kirimkan melalui pesan Telegram itu akan
tersimpan di Pocket.

Hal itu membuat ruang penyimpanan masih aman karena tidak ada aplikasi
tambahan yang perlu dipasang dan juga masih tetap mudah untuk menyimpan link.

Apakah ada bot Telegram lain yang menurut kamu berguna? Bisa share di kolom
komentar.
