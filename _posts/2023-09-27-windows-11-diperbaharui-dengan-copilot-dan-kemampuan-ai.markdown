Microsoft telah mulai meluncurkan pembaruan besar untuk Windows 11, memperkenalkan beberapa fitur baru. Salah satu tambahan yang paling menonjol adalah Windows Copilot, asisten digital bertenaga AI yang memungkinkan pengguna untuk mengontrol pengaturan, meluncurkan aplikasi, dan mendapatkan informasi melalui tulisan. Copilot muncul di sisi kanan Windows 11 dan terintegrasi dengan banyak bagian OS.

Pembaruan ini juga menghadirkan kemampuan AI ke beberapa aplikasi bawaan Windows. Microsoft Paint mendapatkan pembuatan gambar yang didukung oleh integrasi DALL-E, memungkinkan pengguna untuk membuat gambar yang unik dengan memasukkan petunjuk teks. Snipping Tool mendapatkan fitur ekstraksi teks dan penyuntingan, memungkinkan penyalinan teks dari gambar dan secara otomatis menyembunyikan info sensitif. Aplikasi Foto akan memburamkan latar belakang secara otomatis.

Peningkatan tambahan termasuk tampilan yang lebih modern untuk File Explorer, kontrol pencahayaan RGB asli yang disebut Pencahayaan Dinamis, dan dukungan untuk masuk tanpa kata sandi melalui tombol pintas. Aplikasi Windows Backup baru membantu memigrasi pengaturan dan aplikasi ke PC baru.

Sementara beberapa fitur seperti Paint dan Snipping Tool yang diperbarui akan diluncurkan dalam beberapa bulan ke depan, pembaruan dapat diperiksa secara manual untuk saat ini melalui Pembaruan Windows.
