Sudah satu bulan saya memakai Daihatsu All New Terios X Deluxe. X Deluxe ini merupakan tipe rendah dari dua tipe Terios di Daihatsu.

Ini beberapa hal yang bisa saya rasakan:

### Kelebihan

+Model suka, ngga banyak chrome, velg item pula.\\
+Tinggi, genangan air, gundukan, lobang dijalan ngga kepikiran.\\
+Kamera mundur membantu banget (masuk poin positif krn jarang2 tipe rendah dapat kamera mundur).\\
+Lampu depan LED nya terang.\\
+AC ‘digital’.\\
+HU Kenwood, enak suaranya.\\
+Bagasi luas, walau dengan baris ketiga dipakai.

### Kekurangan

-Bug getaran ketika putar maksimal\\
-Bug suspensi(?) depan kanan yg bunyi nguk nguk kaya bis malam.\\
-Suspensi cenderung *stiff*, mungkin untuk mengurangi lumbung. Empuk ketika *full load*.\\
-AC belum ada mode auto.\\
-Suara mesin/gardan masuk.\\
-Bug(?) AT nya pas jalan *idle* lalu pelan dikit langsung turun gigi, biasanya kalau AT lain dia akan turun gigi ketika akselerasi kembali atau memang rpm nya terlalu rendah.\\
-Spion ngga *auto retract*.

Itu beberapa hal yang saya rasakan selama satu bulan ini. Semoga nanti setelah service pertama beberapa bug bisa diatasi. Akan saya update.
